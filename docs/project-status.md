# Project Status

Open Drug Lab is in early alpha.

## Current Status

| Area | Status |
| --- | --- |
| Molecule CSV validation | Available |
| RDKit descriptors | Available with RDKit environment |
| Rule flags | Available |
| HTML reports | Available |
| Run manifests | Available |
| ADMET model predictions | Not implemented |
| Docking | Not implemented |
| Molecular dynamics | Not implemented |

## Maintenance Goals

The project is maintained with these priorities:

1. Keep examples reproducible.
2. Keep scientific language conservative.
3. Prefer trusted upstream chemistry tools.
4. Make failures understandable for learners.
5. Add workflows only when they can be tested.

## Adoption Signals We Care About

- Users running the demo workflow successfully.
- Issues that report real setup or workflow friction.
- Contributions that improve reports, docs, validation, or reproducibility.
- Teaching labs or study groups using the examples.
- CI catching broken workflows before users do.

## Non-Goals

- Replacing RDKit, OpenMM, DeepChem, OpenFE, or docking engines.
- Making medical claims.
- Ranking real therapeutic candidates.
- Handling proprietary or sensitive molecular data in public examples.
